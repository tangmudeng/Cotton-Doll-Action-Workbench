# r3 裤口与大腿交界修订

用户指出 r2 在近侧裤口外缘有尖角，抬腿中段尤其明显。分层检查确认主要是裤衩外侧与大腿外轮廓不一致，不能只通过移动腿片隐藏边解决。

独立候选：`spine_samples/video_reference_right_front_split_20261121/candidate_r3`。保留 r2 和已验收的 pixel_sync 样板。

最终实现以同一视频交界位置约束裤衩与近侧大腿，增加两处裤衩外侧控制点，并将裤衩/双腿的源轮廓标记对齐到 PSD alpha 边缘。重新拟合 IK 材质点和变形轨道。未改变七张纹理、图集或原基线约束拓扑。

过程中尝试过单独移动裤衩角点、收缩腿根以及将脚掌吸附到视频二值轮廓，分别出现尖角转移、轮廓缺口或边缘波纹，均未保留。最终 fit_surface_r3.py 不含视频轮廓吸附代码；以共享交界和原 PSD 连续表面为准。不要把过程测试文件当最终状态。

24 帧最终回导对照已生成；Spine 4.2.43 新建空工程导入与回导，单骨架，193 次采样无翻折，回导顶点最大差 0.012558 px，材质锚点误差 0.08616 px，首尾顶点差 0。浏览器实测手脚放大、骨骼叠加、逐帧及插值播放，停留在 68 帧供用户复核。

辅助白底轮廓测量：裤口 ROI x380:435/y350:405，全 24 帧平均 IoU 在阈值 240 下从 r2 的 0.9082 提升到 r3 的 0.9438；230/248 阈值同样改善。下身全局变化较小。此统计依赖颜色和裁剪，只支持局部轮廓变化方向，不能证明视觉验收通过或关节真实。

用户于 2026-11-21 明确确认 r3 验收通过。最终包 `right_front_split_psd_candidate_r3.zip` 已更新验收元数据，CRC/SHA 结果与文件数见 `package_audit_r3.json`；原动画、纹理和拟合数据不变，验收哈希见 `candidate_r3/acceptance.json`。PSD 与视频腿形、脚掌细节仍有差异，但本版已获用户认可。没有接入正式 05 自动生成入口；完整工艺与后续规划见 `docs/05_PSD_ACCEPTED_WORKFLOW_AND_PLAN_20261121.md`。

重建顺序与 r2 相同，使用 `_r3` 脚本：build → fit_surface → fit_ik → quantize_spine → apply_surface → export → audit；随后 `CANDIDATE_DIR=candidate_r3` 运行 render_candidate.py，运行 review_r3.py 生成最终对照，再运行 package_candidate_r3.py。导出必须使用 export_r3.py 的全新临时工程，避免同名重复导入追加骨架。
