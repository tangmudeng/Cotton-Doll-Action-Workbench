# 05 六步体验

打开 http://127.0.0.1:8770/studio_v3/#spineRig 。

1. **选视频**：在“视频参考”选已有视频，或上传新的 AI 视频。
2. **确认片段**：点击“分析视频并推荐区间”，查看五帧对照与循环视频预览。选候选片段，必要时调整起止帧。非循环动作会提示“未确认循环”。
3. **自动制作**：点击“确认区间并自动生成”。自动执行逐帧识别、原像素分割、时序 IK 拟合、附件绑定和动画生成。刷新后可继续查看进度；失败时点“重试 / 继续自动生成”。
4. **检查效果**：完成后进入“动画核查与导出”。播放动画，查看“自动检查结果 / 异常”和完整逐帧对照；皮肤对齐不等于关节正确，需要一起核对。
5. **Spine 验收**：点击“下载 Spine 待验收检查包”，在 Spine 打开 walk.spine，激活 reference_cycle 播放。检查包不代表已验收。
6. **正式交付**：确认效果和诊断后，勾选核对确认，点击“登记整段验收通过”，再导出正式包。输入修改后须重新生成与验收。

通常不需要开启“手工纠错”。结构错误会阻止验收；无法确定的关节与遮挡显示在诊断中，由用户判断。已验收右前 r6、右后 r4 保留，不因新候选建立而改变。

当前范围：均匀背景单角色、60 秒以内视频，每次制作最多 120 帧。区间建议依据画面运动和重复性，不保证动作语义与接缝合格。完整睡觉动作的骨骼效果尚未验收；目前仅验证它的区间分析回退。附件保留源像素，不补画。

同视频重复制作可复用来源哈希、源帧哈希、模型与算法版本一致的机器识别缓存；不复用人工修订工程的坐标、验收或其他视频素材。


2026-11-21 更新：可直接在载入工程后手动改起止帧，按自选区间建立独立工程。界面按选段、生成、检查、检查包、验收、正式交付排序。图集报告显示页数与基础RGBA占用；当前逐帧模式不等于可复用换装资产。详细自查见 `05_SELF_AUDIT_20261121.md`。
