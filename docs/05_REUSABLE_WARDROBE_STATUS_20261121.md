# 05 换装复用验证接续

用户授权执行固定网格＋有限姿态替换＋组合换装的独立验证。当前分支 codex/reusable-wardrobe-prototype，尚未提交或推送本轮改动。

实验目录：spine_samples/reusable_wardrobe_20261121。入口 review.html；真实工程 fitted/wardrobe_review.spine；完整包 wardrobe_experiment.zip；详细结论 REPORT.md。

用户先提供基础角色-正式/图层 69.png（独立正面背带衣），随后提供棉花娃娃/图层 10.png（同朝向穿衣原画）。最终候选衣物来自后者，避免正面透视拟合导致的变形。两张原图都未修改。

当前：身体15张纹理＋衣物5张，2020×368单页，2.84MiB基础RGBA；17根骨骼（原16根加head_visual）、4组IK、同一walk_reuse动画、body/base与outfit/green_overalls两套命名皮肤。default空皮肤需明确告知用户选择命名皮肤。

实际Spine4.2.43导入回导、230个采样检查通过；最大顶点差0.1074px；可见原像素覆盖的网格翻折观察0，透明区域8次观察保留。纹理RGB来源检查通过，已验收pixel_sync基线166文件哈希未变。

**不是合格交付。第一阶段身体复用视觉质量门尚未通过。** 肩根/腋下、腰髋和腿根接缝，以及少量姿态替换跳动仍需处理；不要把衣服遮住缺口算成裸身通过。衣服轮廓、拟合位置和权重参数本轮由脚本明确指定，并不是自动换衣系统。

下一步应继续修复/审阅身体母版和衣物连接，确认外观方向后再验证第二个独立同朝向动作的纹理复用，最后才接回05。原用户通过的动画不得覆盖、撤销或传播验收。用户已说明没有额外视频；新原画也没有裸身隐藏区域。不能在无来源像素处偷偷补画。

实验的低成本失败证据在trials/；中间缓存probe.json、clean_sources/、frame_checks/等由实验局部.gitignore忽略，可按REPORT.md重建。正式工作台代码未修改。
