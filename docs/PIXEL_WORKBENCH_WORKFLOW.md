# 05 源像素骨骼工作流

2026-11-20。目标：参考 AI 视频，在工作台完成附件、骨骼/IK、同步动画和真实 Spine 工程导出。

## 六项工作与状态

1. **冻结样板**：`pixel_sync_20261120` 不改动。166 个基准文件在复制前核对 SHA256。用户验收仅属于该样板。
2. **制作规则**：原视频连续抽帧；7 个逻辑部件、每帧可有独立附件；16 骨骼、4 双骨 IK；按同一源姿势反算蒙皮；骨骼与附件均 stepped。禁止用连续骨骼拉动上一帧皮肤。
3. **数据接入**：新增独立 `walulu-pixel-project/1` 工程，保存视频哈希、原尺寸/帧率、帧索引、轮廓/遮罩、关节点、图层顺序和审核状态。旧版失败附件不参与新流程。
4. **工作台界面**：05 分为视频参考、图集拆件、骨骼/IK、动画核查与导出。支持原位组装、单件查看、轮廓重描、关节点点选、图层调序、逐帧播放、帧内中点/切换前检查、缩放、撤销/重做和本机持久保存。
5. **真实导出**：当前输入生成网格、图集、JSON；Spine 4.2.43 CLI 导入 `.spine` 后再次导出 JSON；官方运行时比较回导前后顶点。任何输入修改都会清除导出就绪状态。
6. **复用验证**：用户再次提供同一视频，因此使用第85帧作为起始标注，追踪未纳入基准的86–90帧。已完成导入、遮罩、人工校正、绑定、导出及回导；这是同视频新帧区间验证，**不是新角色泛化验收**，也不是完整新步态循环的视觉验收。

## 使用

在工程目录执行：

```powershell
py -3 server_v3.py --host 127.0.0.1 --port 8770
```

访问 `/studio_v3/#spineRig`。开发验证曾使用8772，完成后新版已启动在原8770端口。

05 需要 Python 的 numpy、Pillow、opencv-python（`py -3 -m pip install -r requirements-pixel.txt`）、Node.js，以及已授权的Spine 4.2.43。默认CLI路径为 `E:/MyTools/Spine/Spine.com`；其他电脑通过 `SPINE_CLI` 环境变量指定。生成阶段不需要Spine桌面UI，真实工程导出阶段需要CLI。

### 已验收样板

点“从验收样板创建”，再点“动画核查与导出 → 保存并生成当前动画”。未改动的工程直接复制已验收 JSON、图集和附件，不进行有损重建。生成器仍会执行 23×5 个时刻的运行时核查。

修改锚点、轮廓或图层后保存，再生成；新结果不继承用户验收。原目录永远不写入。

### 新视频

1. 选择视频文件和包含两端的源帧范围，每次1–120帧，文件最大96MB。
2. 对起始帧描出7个部件轮廓，并标注10个端点、4个肘膝。
3. 可选择“从此帧追踪后续轮廓 / 锚点”得到草稿。该操作保存修改并覆盖后续标注；旧版本保留在 `revisions/`，当前页面可撤销追踪结果。
4. 对均匀背景视频，可勾选“均匀背景前景补全”。算法从当前帧四角估计背景，再将新露出的前景分配给邻近部件，保留原帧 RGB。多角色、复杂背景、遮挡和部件身份仍需人工判断。
5. 每帧分别确认附件和骨骼。点击锚点下拉菜单选择关节，再在原图点选位置。追踪不会自动标记审核完成。身体遮挡点属于推定，不是由视频确定的解剖事实。
6. 保存、生成、查看帧内切换前效果，再导出 Spine ZIP。

“同视频载入起始标注草稿”只在视频内容 SHA256 与原参考完全相同时可用，且起始帧必须在63–85中。它复用已验收的标注/遮罩结构，附件 RGB 仍取自本次导入帧；不是将旧 PNG 填入新视频。

## 自动化与人工边界

自动：解码/哈希、光流草稿、均匀背景前景补全、原像素裁片、图集、多权重网格、双骨IK、同步时间轴、数值检查、Spine CLI回导、ZIP与校验清单。

人工：动作区间、部件语义、肩髋隐藏位置、肘膝方向、手脚端点、遮挡顺序、轮廓审核、最终视觉验收。光流可能跟错遮挡处；不能因为组合画面吻合就认定骨骼标注正确。

本轮复用测试中曾出现远脚缺像素、远肩/远脚锚点漂移。前者通过当前帧前景补全修复，后者按原帧人工修正。保留审核门槛，不将这些步骤包装成全自动完成。

## 数值和导出边界

- 每帧检查5个时刻：起点、25%、50%、75%、99.9%。同时检查源图坐标、附件名称、非空三角形、骨骼关节与端点、帧内顶点漂移。
- 帧内漂移阈值0.001px；导出源坐标/顶点容差0.25px；关节/端点容差0.2px。容差反映 Spine JSON 的数值取整，不代表美术质量通过。
- 在绑定前按 Spine 持久化精度量化位置/角度及缩放，防止导入后再取整引入变形。
- IK 弯曲方向在一段动作中固定；遇到方向翻转会停止生成并提示校正。未实现跨方向切换的独立绑定方案。
- 仅 `reference_cycle` 是当前生成器的正式动画；复制基准时仍保留其 `test_*` 诊断动画。
- 图集可分页，每页4096；PNG不预乘RGB。部件颜色逐像素来自当前源帧，不做生成式补画。
- 循环末尾返回首帧；截取非循环片段时，末尾可能跳变，必须选好步态区间。
- ZIP包括 `.spine`、运行时JSON、图集、parts、原帧、遮罩、工程输入、来源清单、数值报告和SHA256。解压后打开 `.spine`；在Spine中点 `reference_cycle` 左侧圆点再播放。
