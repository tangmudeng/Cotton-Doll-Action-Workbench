## 4. 流程自查与排版
六个操作区依次为：选视频/帧区间、自动制作、整段像素/骨骼核查、Spine检查包、登记验收、正式交付。验收移到检查包之后；不再把验收按钮放在视频选择前。检查视图标签移除重复步骤编号。手动纠错仍默认关闭。
测试：4项可靠性、11项自动化、6项管线（真实Spine CLI）、4项视频分析、16项前端状态检查通过。新增覆盖：手动区间独立工程、无效帧号拒绝、坏JSON/截断留档、精确去重、每区域像素一致、并发上限及单帧失败保留缓存。浏览器验证两种自选区间到生成/检查包，未代替用户视觉验收。

## 6. 换装判断与建议
现模式若每个服装也逐帧生成，会随帧数、动作数和服装数增长；不适合直接批量扩展。7类逻辑部件、16骨骼、4IK只约束结构，不保证图集小或服装可复用。
建议保留现模式为高还原参考，另验证可复用换装模式：固定角色骨架和少量基础附件，靠骨骼/网格形变产生主要运动；头部只在确有转向/表情变化时使用少量替换图；时装以独立slot/skin绑定同一骨架，处理袖口、裤口、鞋与身体遮挡。衣服不必重新复制头部与裸露身体图，按常用组合/目标设备制定图集预算。
不能直接将逐帧头图删成一张：AI视频有视角和轮廓变化，可能再次导致拉扯或缺像素。也不能只降低PNG文件大小就认为解决内存/换装问题。应先用同角色一套服装、两个动作验证复用与视觉质量，再决定资源预算和生产规范。该换装方案本轮未实施，未声称换装质量已通过。
