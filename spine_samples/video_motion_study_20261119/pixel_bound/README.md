# 原帧附件 IK 试装

这是视觉试装候选，尚非最终可复用的少量附件骨骼。15骨骼、4原生IK约束、7部位、23组姿态共161个附件。动画 reference_cycle。

所有附件RGB来自原视频对应帧，没有生成补画。每帧用可见像素分区，边缘保留3像素原帧重叠；并未补全不可见区域。四肢网格实际绑定上下段IK骨骼，头/躯干/裤衩暂用root上的姿态附件。姿态附件每源帧切换，因此外观保真主要来自密集原帧姿态，不能声称少量附件即可泛化任意动作。后续需修分区边界、减少冗余附件并验证新姿态。

打开source_pixels_ik_v2.spine并保持parts目录同级。浏览器通过HTTP服务打开review.html。pixel_manifest.json含逐附件帧号和裁剪框。原始RGB逐像素校验通过，但旋转/网格渲染会插值；分区边缘仍需视觉审核。
