# 小幅 IK 连接权重候选（2026-11-20）

本轮按用户选择，先支持原视频动作附近的小幅调整。当前是有改善、仍有缺陷的候选，不是最终验收版本。

## Spine 打开与播放
打开 walulu_limited_ik_v2.spine；parts 目录必须在同级。
进入动画模式，点击 reference_cycle 行最左侧的激活圆点，然后播放。只点击名称可能仅选中条目，时间线仍为空。
可比较 walk_loop_22_candidate；test_near_hand/test_far_hand 为±5px横向测试，test_near_foot/test_far_foot 为±4px横向测试。
本轮工程经 Spine 4.2.43 导入重导出；新版尚未在桌面编辑器中实机验收。上版已实机确认“未激活动画”是看不到运动的原因。

## 本轮变化
肩髋附近与躯干、裤衩重叠的网格增加 torso/pelvis 权重；向肢体远端逐渐恢复原有上下骨权重。每个附件在其源姿态逆算局部坐标，保留原姿态。
没有补画，也没有用整帧贴图替代骨骼。161张部件图片和原包SHA256一致。
reference_cycle仍为23帧原帧保持；新增22帧候选，使用63–84帧、85时刻回首帧。原视频63与85本就接近，候选避免在相似姿态上额外停留一帧；不宣称完全无缝。
未采用全片相似度最高的67→89候选，因为86–89尚未建立审核过的拆件与绑定。

## 验证
23姿态×4肢体×4轴向扰动=368次，网格全部可绘制且顶点有限。原动作最大坐标差0.005524px。
数值通过仅说明结构稳定，不代表所有姿态视觉通过。组合XY扰动、任意角度、大幅改动作未验收。
70帧远手+5px时，腰侧/远手区域相对原帧多出的轮廓像素199→86；-5px时相对原帧覆盖减少62→30。并未归零。
这些是相对原帧的轮廓差，不是变更姿态的真实标准答案，也不能把脚正常移动的轮廓变化当作裂缝。
