# 右前行走 Spine 样板

解压后，保留工程旁的 parts 文件夹。用 Spine 打开 walulu_approved_walk_v2.spine，进入动画模式，点击 walk 左侧圆点激活动画，再按播放。setup 是静态绑定姿态。

工程为 Spine 4.2.43 格式，已在 4.3.26 中打开并播放。walk 循环 0.875 秒，含 12 根骨骼和 7 个网格附件。walk.json、walk.atlas、walk.png 是运行时资源。

外观以已审核的迈步和站姿图为基准。保留头、近侧手臂和双脚，远侧手臂取自站姿图。躯干和裤衩采用连续补画，允许局部纹理变化以减少运动接缝。

walk_preview.gif 可直接预览循环。通过本地 HTTP 服务打开 review.html，可以同步查看参考视频与骨骼动画。点击「审核迈步姿态」可对照 0.25 秒的组装效果。

从 Spine 工程重新导出的 JSON 已通过官方运行时的 193 次采样检查，未测到网格三角形翻折，首尾采样一致。动态美术效果仍待确认，05 工作台接入以确认后的样板为准。
