# 右前行走 v4 待验收样板

本轮针对用户确认的画面右侧远手和裤衩形状：重新补画远手，减弱弯钩轮廓；裤衩改用圆弧裆部、连续裤口；保持与原附件中间肤色、布料颜色一致。生成图片及颜色校正见 repaint_audit.json。

恢复手臂上下段之间的渐变权重与小幅肘弯，手掌末端保持刚性。对原视频64—85帧人工拟合的旋转曲线使用周期单调Hermite插值，烘焙为43个可编辑时刻，避免角度过冲，改善急停与循环节奏。添加轻微髋部摆动。骨骼数量仍为12，没有用增加骨骼来掩盖附件问题。
