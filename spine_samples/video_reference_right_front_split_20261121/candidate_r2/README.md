# 右前行走 PSD 网格蒙皮候选 r2

本候选根据用户的源视频与右前图层 PSD 制作。它仍等待用户视觉验收，不是已通过的生产资产。

## 检查方式

1. 先打开 `review.html`，逐帧检查 59–82，并以 1/4 速度播放。
2. 查看 `six_pose_comparison.jpg` 和 `body_contact_sheet.jpg`；重点核对裤口、大腿根、手臂摆幅和脚掌朝向。
3. 开启“蒙皮上叠骨骼”，确认 IK 链和皮肤形变同步。
4. 在 Spine 4.2.43 打开 `right_front_split_psd.spine`，选择 `video_right_front_split_59_82` 循环播放。`psd_bind_pose` 是静止绑定姿势。

## 动画与蒙皮

- 区间为源帧 59–82，24 fps；第 83 帧只作区间结束边界，不进入动画。
- 图集仍为七张固定 PSD 原始裁片。没有视频逐帧换图、补画、调色或贴图替换。
- 16 骨骼、四组双骨 IK、层级、顺序、弯曲方向与已验收 `pixel_sync_20261120` 基线一致。
- `torso`、`shorts`、双臂及双腿的固定 PSD 网格有动画 deformation 时间线。双腿上缘收进裤衩遮挡区，裤口、大腿根轮廓和上身下缘根据视频姿势变形。
- 脚掌由固定 PSD 表面参与网格变形，不再宣称为刚性区域。形状会变化，手脚需要继续由用户按视觉效果评估。
- 肩/髋/膝/肘的内部解剖中心在像素中不可直接观察。本候选在九个姿势做了人工轮廓标注，逐帧插值；部分遮挡关节仍是估计，不是自动从视频恢复出的真值。

## 技术复核

- 由空工程导入 Spine 4.2.43 后重新回导，实际只有一个骨架。
- 官方 Spine runtime 193 个时间点复核：无翻转三角形，首尾顶点差为 0，IK 骨端到目标最大误差约 0.0000002 px；回导网格最大顶点差约 0.012 px。
- PSD 材质锚点和蒙皮网格的内部一致性最大偏差约 0.114 px。这个数值说明动画轨迹与本候选选择的材质锚点匹配，不证明隐藏的关节解剖正确。
- 回导骨关节与估计膝/肘位置最大差约 0.671 px。远侧被遮挡时，估计误差可能更大。
- 24 帧二值轮廓的阈值敏感对照在 `silhouette_audit.json`。它是白底阈值测量，背景阈值和颜色影响结果，只用于发现大范围轮廓偏差，不作为像素级合格证明。
- 六个关键姿势与 r1 的比较在 `six_pose_comparison.jpg`。r2 主要改善下身轮廓和固定附件在运动中的跟随；仍能看到 PSD 与视频画风、裤衩颜色和局部形状不同。
