# 使用验收骨架绑定 PSD

本轮按用户纠正，以 `pixel_sync_20261120` 为唯一骨架和动画基准，重新绑定最新版《右前图层.psd》。这是待视觉审核的绑定修正版，不代表最终皮肤效果已通过。

## 查明的错误

上一轮先按 PSD 自建关节，再重定向动作，造成远侧手臂与远侧腿的 IK 弯曲方向与验收版相反，执行顺序不同；还加入了投影缩放和人工胯部轨迹。这些都偏离了本轮要求。

本轮直接复制验收版的 16 根骨骼、4 组 IK、slot 到 bone 的关系，以及 reference_cycle 的全部骨骼关键帧。除 root 的一次静态整体缩放和平移外，骨骼定义保持一致；没有新的骨骼、骨骼缩放时间轴或人工轨迹。

## IK 与层级

| IK | 上下骨链 | 目标 | 执行顺序 | bendPositive |
|---|---|---|---:|---|
| arm_far_ik | arm_far_upper → arm_far_lower | arm_far_target | 0 | true |
| leg_far_ik | leg_far_upper → leg_far_lower | leg_far_target | 1 | false |
| arm_near_ik | arm_near_upper → arm_near_lower | arm_near_target | 2 | true |
| leg_near_ik | leg_near_upper → leg_near_lower | leg_near_target | 3 | true |

头部继续使用验收骨架的 head_control，父骨骼为 torso；保留原骨长、角度和目标关系。绘制顺序沿用验收版，近腿在远腿前面，裤衩在腿上方。

## PSD 附件如何适配

- 输入 SHA256：`ba7c6d3b0b1bb1c5521184257c2f2f2592eda9f098ee4a2e04e1eb8a6ebbe8cd`。
- 骨架统一放大 1.68 倍并平移到 PSD 坐标；这一变换只发生在 root，不逐帧改变，也不分别改动四肢骨长。
- 四肢附件用 PSD 上的根部和端部定位点静态对齐到验收骨架的绑定姿势。手臂做相似变换；腿部调整纵向长度与方向，同时保留原横向宽度。对应矩阵见 attachment_registration.json。
- 因为两种素材的静态姿态和比例不同，绑定后的四肢位置与尺寸不再严格等于 PSD 原位组装；改变的是附件网格的位置与权重。
- PNG 仍为用户新版 PSD 的七张贴图，哈希与导入母版一致。没有补画、旧视频拆件贴图、逐帧换图或逐帧附件变形时间轴。
- 大腿根部向 pelvis 过渡，四肢主体绑定上下骨；脚掌部分绑定已有 IK target 与下骨的混合权重。未新增脚掌骨。

## 如何核对

1. 完整解压包，用 Spine 4.2.43 打开 **psd_bound_pixel_sync.spine**。
2. 进入动画模式，选择 **reference_cycle** 并循环播放；此动画确实有骨骼关键帧。
3. 网页 review.html 左边为原视频与验收骨架，右边为 PSD 蒙皮与回导骨架。
4. 勾选“显示骨骼”和“验收骨架叠加核对”：青色粗线为验收版，红色细线为当前版，二者应逐帧重合。
5. 取消显示骨骼检查蒙皮；“手脚局部”放大肩髋、膝和脚掌；“绑定姿势”查看静态附件与骨架对齐。
6. 网页离线包需 HTTP 服务：在解压目录运行 `py -3 -m http.server 8771 --bind 127.0.0.1`，访问 `http://127.0.0.1:8771/review.html`。

动画保留验收版原有 24 fps 阶梯曲线及 0.9583 秒周期，本轮不额外平滑或改变节奏。

## 实际检查

Spine 4.2.43 真实导入并回导。93 个时刻比较所有骨骼世界位置和变换矩阵，统一对齐后骨架位置最大差约 1.71e-13 px；IK 的链、目标、顺序、方向、mix、softness、compress、stretch 等运行时参数一致。

蒙皮回导最大顶点差 0.01142 px；对齐后绑定姿势顶点误差小于 0.000028 px；三角形翻折 0；首尾顶点差 0。完整 23 帧已渲染，浏览器检查了播放、逐帧和叠加效果。

这些证据验证骨架复用和文件一致性。PSD 的厚度、轮廓、接缝及动作时的皮肤体积仍需视觉审核；不能据此宣称与视频逐像素一致。头部外观和单视角限制仍来自用户原画。

## 复现

项目中的 bind_accepted.cjs 读取不可变验收骨架与本轮 PSD 导入纹理，执行静态附件对齐和权重绑定。导入新命名 .spine 后回导至 roundtrip，再运行 verify_binding.cjs 与 render_walk.py。verify_binding.cjs --draft 只用于导出前检查，不能算作回导通过。

原验收基准和之前的 PSD 候选均保留，没有覆盖。下一步应在这一骨架基准上修蒙皮；若确需改变骨架或 IK，应先明确提出原因和影响。
