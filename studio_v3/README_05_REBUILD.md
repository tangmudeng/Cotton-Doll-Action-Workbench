# 05 骨骼动画重建 · 2026-11-19

本轮按 Meowa 的「动画与骨骼 / 图集拆件」双工作区和三栏加时间轴布局重建入口，并将指定本地视频「右前行走.mp4」接成独立、哈希校验的动作参考。

## 已实现
- 七个逻辑件：头、身体、短裤、双臂、双腿；旧裁片只作待审起点。
- 本地视频 SHA-256 `9c08a83c...44e8fc`，864×480、24 fps、107 帧；107 张 PNG 参考帧逐帧哈希记录。工作区使用 68–88 帧（0.833 秒）作为重复步态候选，不代表循环验收通过。
- 七件初始观察建议按帧 68、72、80 手工整理并明确标为待审建议；工作区可逐帧重新核验可见性、轮廓和遮挡。
- 依据记录后，在源图上多边形重裁，生成透明 PNG；更换裁片清空该件关键帧。
- 父子骨骼：躯干带动头、双臂和短裤；短裤带动双腿。四肢在整张附件内部增加肘膝弯曲控制。
- 位移、旋转、弯曲关键帧及线性/阶梯插值；循环首尾配对、同步预览。
- 小网格平滑权重与单图光栅化，避免分片 Canvas 裁剪的三角接缝。
- 撤销/重做、浏览器草稿、JSON 工程下载/载入及来源和结构校验。

## 验收边界
这是七件附件的骨骼/柔性预览原型，不是已验收的 Spine 工程。当前使用指定的本地视频与候选周期；旧源图和裁片仍需按该视频审定。初始关节位置为估计，尚未拟合完整行走动作。尚无通用视频导入、自动拆件、IK、隐藏面补画或正式 Spine 权重导出。候选观察不会计入人工核验。

旧 v2/v3/v4 失败候选已退出默认运行入口；保留原实验数据与评审证据供追溯。没有将任何候选标为生产通过。

## 验证
Node 语法检查、新数据模型测试、原序列帧两项回归通过；生命周期回归为 73 项、1319 条断言。
浏览器验证了素材加载、双页签、关键帧、保存恢复、撤销、依据记录、透明裁片生成及播放停止。测试裁片草稿已被原始七件基准覆盖。
JSON 数据往返通过模型测试；浏览器下载/文件选择载入尚未完成端到端验证，不将其作为已验收项。
